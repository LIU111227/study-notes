# study-notes

> 学习笔记 skill —— 把对话中学到的东西，按**康奈尔笔记法 + 费曼技巧**自动沉淀进 Obsidian 知识库。

这是一个 [SKILL.md](https://skills.sh) 格式的跨 agent 通用技能：在哪个 AI agent 里学习，就在哪个 agent 里说一句"记笔记"，它会把**当前对话的新内容**提炼成结构化笔记，按知识脉络合并进你的 Obsidian 仓库。

## 特性

- **增量处理**：只总结当前会话"两次调用之间"的新消息（游标管理）——不重复、不遗漏、不回填历史
- **智能落位**：每次先读完整索引与相关主题文件，再判断新知识放哪
  - 属于已有章节 → 补充进去（先学架构、后补细节的场景不会开新文件）
  - 新主题 → 新开文件并按知识前后关系插入索引的**合适位置**（不是默认文末）
  - 已有知识点 / 闲聊 / 纯操作问题 → 不记
- **修正优先于追加**：新内容推翻笔记中旧表述时直接改写，不产生"更正：…"式冗余
- **拆解导入**：旧笔记（本地文件 / 粘贴文本 / 飞书文档 URL）一键拆解入库，重叠内容自动合并去重
- **每周全量审查**：自动检查前后矛盾、冗余、章节顺序、三栏劣化；结构性改动先列方案等你确认
- **笔记方法论内置**：康奈尔三栏（线索 / 主栏 / 总结）+ 费曼总结栏（只记最终正确的一句话解释）

## 笔记格式

每个知识点在主题文件中独立成块（Obsidian 双链索引，可按线索栏自测）：

```markdown
## <知识点标题>

### 🧵 线索栏
- 这一块讲什么：一句话
- 关键问题：这个知识点回答了什么问题？（供日后自测）

### 📖 主栏
- 核心概念：…
- 要点 / 细节：…
- 例子：…
- 易错点：…（写修正后的版本）

### 💡 总结栏（费曼）
<一句话，用自己的话，不用行话>
```

知识库组织为 `vault/<学科>/index.md`（章节顺序）+ 每主题一个 md 文件。

## 安装

依赖：Python 3.10+（仅标准库）。

**Claude Code**

```bash
git clone https://github.com/LIU111227/study-notes ~/.claude/skills/study-notes
```

**DeepTutor**（装到所用 workspace 的 skills 目录）

```bash
git clone https://github.com/LIU111227/study-notes \
  ~/deeptutor/data/user/workspaces/<你的workspace>/skills/study-notes
```

**其他兼容 SKILL.md 的 agent**：把仓库放进对应 agent 的 skills 目录即可，`SKILL.md` 中的指令均为工具无关写法（用宿主的 shell 执行自带脚本）。

## 配置

目的地不写死，三层优先级：

1. 调用时随口指定（"把笔记记到 XX"，本次生效）
2. 全局配置 `~/.config/study-notes/config.json`：

```json
{
  "vault": "/mnt/d/Obsidian/doc/learning",
  "default_subject": "视觉"
}
```

3. 配置不存在时首次引导：skill 在对话里问你两个问题（vault 路径、学科目录名）并自动写入

游标与"上次审查日期"存在 `<vault>/.study-notes/state.json`（放在 vault 内，跨 agent 共享同一份状态）。

## 使用

在任意对话里说：

| 说法 | 触发 |
|---|---|
| "记笔记" / "整理笔记" | 增量：总结本会话自上次以来的新内容并落位 |
| "拆解这个笔记入库：\<路径/文本/飞书链接\>" | 导入：旧笔记按知识点拆解、合并去重 |
| "审查笔记" | 全量：矛盾/冗余/顺序/三栏质量检查 |

执行模型 = 当前会话的模型（在哪个 agent 里用就跟随哪个 agent 的模型）。

## 工作原理

```
对话中说"记笔记"
  → fetch_new.py   探测宿主 agent，拉当前会话游标后的新消息（含 2 条衔接窗口）
  → notes_state.py 游标与审查日期管理（状态存 vault 内）
  → agent 读 index.md（全局结构）+ 受影响主题文件
  → 按 SKILL.md 规则判断落位（归属/新开/修正/不记）
  → 写入笔记文件 + 推进游标 + 一句话汇报
```

两个脚本均为纯标准库 Python，只读对话数据、只写 vault 目录。

## 扩展新 agent 适配

`scripts/fetch_new.py` 的宿主适配是插件式的：实现一个 `fetch_<agent>(cursor, max_chars)` 函数
（返回统一 JSON 结构），并在 `detect_agent()` 里加一个探测分支即可（现有 DeepTutor / Claude Code
两个实现可直接参照）。

## 目录结构

```
study-notes/
├── SKILL.md                 # 方法论与流程（agent 读取的主文件）
├── references/
│   └── placement.md         # 章节归属与插入位置判断细则
└── scripts/
    ├── fetch_new.py         # 宿主探测 + 当前会话新消息拉取
    ├── notes_state.py       # 游标 / 每周审查状态管理
    └── notes_io.py          # 配置与学科目录引导
```

## 设计取舍

- 只处理**当前会话**的新消息，绝不扫描其他旧会话（明确不做历史回填）
- 笔记写入直接执行；全量审查中的**结构性改动**（删/并章节、重排索引）先列方案确认
- 模型与目的地都不写死：模型跟随宿主会话，目的地三层可配置
