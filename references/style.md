# 笔记风格细则（写作纪律展开 + 对照示例）

本文件是 SKILL.md"笔记格式"节的展开层：规则的理由、操作方法和对照示例都在这里。
示例统一使用与使用者学习领域无关的中性领域（科举制度），只为示范格式，不为示范内容。

## 1. 开采 vs 压缩（最常见故障的对照）

同一段对话，两种记法的对照。坏版本是"把对话压短"——保留的是聊天叙事；好版本是
"从对话里开采"——保留的是成立的知识。

**假设的对话内容**：用户问科举是什么；AI 解释了科举的由来（隋朝创立、取代九品中正）、
四级考试结构、唐代考生的完整流程（报名→省试→放榜→铨选）；用户中途说"我之前以为是
汉朝就有了"，被纠正；用户总结"所以科举就是古代的高考"，AI 指出这个类比不完全对。

### 坏版本（禁止这样记）

```markdown
## 科举制度

### 🧵 线索栏
- 这一块讲什么：科举
- 关键问题：科举是什么？

### 📖 主栏
- 核心概念：今天聊了科举，其实就是古代的高考
- 要点：我们讨论了科举的由来，你说它是隋朝开始的，我之前以为是汉朝
- 例子：还聊到了秀才、举人、进士这些名词
- 易错点：科举不是汉朝开始的

### 💡 总结栏（费曼）
科举说白了就是古代的高考，很重要。
```

坏在哪（逐条对应写作纪律）：

| 症状 | 违反 |
|---|---|
| "今天聊了 / 我们讨论了 / 还聊到了" | 对话指涉 + 按对话时间线组织 |
| "你说…我之前以为…" | 对话痕迹（对话只是证据源，不是内容） |
| "其实就是 / 说白了" | 口语填充词 |
| "科举是什么？" | 笼统问题，测不出任何具体点 |
| "很重要" | 虚话，删掉后知识不受影响（删除测试不过） |
| "古代的高考" | 未经同构检查的比喻（高考给入学资格，科举给任官资格，机制不同） |
| 全文没有一个机制、一步流程 | 标签化（Thin）：只有名词，没有"怎么运作" |

### 好版本（按这个标准记）

```markdown
## 科举制度

### 🧵 线索栏
- 关键问题：科举解决了什么问题、没有它会怎样？
- 唐代考生从报名到做官要过哪几道关？
- "古代高考"这个类比哪里不成立？

### 📖 主栏
- **是什么**：科举 = 以统一考试成绩取代出身举荐作为任官依据的选拔制度
- **解决什么问题**：此前选官靠世家举荐（九品中正制），官职被门阀垄断；
  科举让平民凭考试获得任官资格，皇权借此打破门阀对官僚系统的控制
- **分哪几部分**：童试 → 乡试 → 会试 → 殿试，四级逐级筛选、逐级减员
- **流程链**（以唐代为例）：
  1. 持地方核发的报考文书到礼部报名 → 资格审查 → 排除商贾、倡优、吏员出身
  2. 礼部主持省试（帖经、杂文、策论）→ 分别考经义记忆与政论能力
  3. 放榜 → 及第者获得"出身"（任官资格，还不是官）
  4. 过吏部铨选（身、言、书、判四项）→ 才正式授官
- **上下游**：上游是学校与家学构成的备考体系；下游是官僚系统（进士出身者升迁显著更快）
- **易错点**：科举 ≠ 汉代察举（察举靠推荐，科举靠统一考试）；科举始于隋而非汉

### 💡 总结栏（费曼）
科举把"谁当官"的答案从"你爹是谁、谁举荐你"换成"你考得怎么样"。而且考试通过
只拿到入场券，还要再过吏部一道面试笔试才真正做官——像招聘里笔试过了（科举）还要
过终面（铨选），两道闸都开才入职。
```

好版本没有一个字提到对话；所有句子单独成立；机制和流程链完整；
"招聘笔试/终面"的比喻每个角色都有对应（笔试↔省试、终面↔铨选、入职↔授官）。

## 2. 认知链各段的写法

| 段 | 写什么 | 不写什么 |
|---|---|---|
| 是什么 | 一句话定义，能独立成立；术语跟白话解释 | 背景铺垫、"其实就是…"式引入 |
| 解决什么问题 | 它替代了什么、没有它会怎样 | "很重要/很有用"式评价 |
| 怎么运作 | 机制、原理、因果链，直讲 | 比喻（比喻只进总结栏） |
| 分哪几部分 | 组成/分类 + 每部分一句话职责 | 光列名词不解释（标签化） |
| 流程链 | 每步 `动作 → 目的 → 产出`，一行一步 | 把流程写成一段散文 |
| 上下游 | 输入输出、依赖关系，[[链接]]相关块 | 与本块无关的延伸话题 |
| 易错点 | 被纠正过的认知，写修正后版本 | 对话中的原始错误表述 |

**缺段规则**：对话里没有的信息直接跳过该段，禁止编造补齐；"是什么 / 怎么运作 / 流程链"
三段全缺 = 这段对话没有可沉淀的知识点，不记。

## 3. 比喻的同构检查

主栏禁比喻。总结栏允许至多一个比喻，且必须通过同构检查：

> 能不能说出比喻里的每个角色对应真实机制的哪个角色？每个对应关系是否在关键
> 层面（因果、方向、条件）上成立？

- **通过例**："招聘笔试过了还要过终面才入职"——笔试↔科举出身、终面↔吏部铨选、
  入职↔授官；关键机制（两道闸、后者才给最终资格）方向一致。✅
- **不通过例**："科举就是古代高考"——高考给出**入学**资格，科举给出**任官**资格；
  输入（年龄段、身份限制）、输出（去哪）、淘汰后的出路都不对应。❌ 用了这个比喻，
  会让人以为考完就直接当官，恰好漏掉铨选这道关键机制。

判据：比喻的**机制结构**要同构，不是"气氛像"。说不清对应关系的比喻，宁可用平实
白话直讲。

## 4. 删除测试与自包含测试

- **删除测试**（逐句）：假设删掉这句话，这一块的知识是否受损？
  - 不受损 → 这句是复述、过渡或虚话，删。
  - 例："科举很重要"删掉后，读者对科举的理解没有任何损失 → 删。
- **自包含测试**（整块）：把这一块复制到一个空白文档，不看原对话、不看库里其他
  文件，能否完全读懂？
  - 出现"如上所述""前面提到的""就是刚才那个"→ 违反（对话/上下文指涉）。
  - 出现未解释的代词或悬空引用 → 违反；改为具体名词或补 [[链接]]。

## 5. 线索栏问题设计

关键问题是为了日后自测，问题质量决定复习质量。

| 坏问题 | 为什么坏 | 好问题 |
|---|---|---|
| 这一节讲了什么？ | 笼统，测不出具体点 | 科举解决什么问题、没有它会怎样？ |
| 科举重要吗？ | 答案只能是"重要"，无信息量 | 为什么皇权要推科举（动机是什么）？ |
| 科举有哪些考试？ | 无序集合背诵，超过 3 项记不住 | 从童试到殿试，每级刷掉的是什么人？ |
| 科举是什么？ | 只测定义复述 | "古代高考"这个类比哪里不成立？ |

规则：优先"为什么 / 怎么做 / 如果…会怎样"（应用与辨别型）；一个问题只测一个点；
1-3 个为宜。

## 6. 每周审查的 Thin（标签化）维度

识别信号：

- 主栏出现"XX 很重要 / XX 广泛应用于… / XX 包括 A、B、C"就结束了——**只有名词，
  没有机制**；
- 读完这一块，无法回答"它怎么运作"或"为什么要这样设计"；
- 流程链缺失，但这个知识点本质上是个流程。

处理：按认知链骨架补写"怎么运作 / 流程链"；对话和已有笔记里没有的信息不编造，
在该段标注"待补"，让用户下次学到时回填。
